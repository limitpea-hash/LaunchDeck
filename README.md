# LaunchDeck · 智能起始页

> 当前版本 **v0.10.9** · [下载 LaunchDeck-v0.10.9.zip](https://github.com/limitpea-hash/LaunchDeck/releases/download/v0.10.9/LaunchDeck-v0.10.9.zip) · [查看 v0.10.9 发布页](https://github.com/limitpea-hash/LaunchDeck/releases/tag/v0.10.9) · [更新日志](CHANGELOG.md)

独立导航与起始页，将常用网站、单层文件夹、底部 Dock 与多规格小组件整理在同一张桌面上。提供开箱即用的 Chrome / Edge 独立新标签页扩展，以及无第三方运行时依赖的本机与可信局域网网页服务。

## 核心特性

- **固定网格直拖与自适应布局** 网站与小组件可直接拖入主网格的空格或占用区，拖动中实时预览卡片让位，松手持久化保存固定格子坐标并支持跨页移动。网页卡片默认 `1×1`，编辑模式下可切换为 `2×2`，单层文件夹与 Dock 保持标准图标尺寸。小窗或短窗自动切换紧凑摘要并提供「查看全部」，移动端支持紧凑总览与舒展分屏切换。
- **平滑悬停自适应 Dock** 底部 Dock 随鼠标悬停向上放大目标图标并联动邻近图标轻微放大，光标在图标间移动或移出时平滑缩放过渡。空间充足时居中展示，图标超出宽度时可横向滚动且悬停项完整可见。
- **月历与天气小组件** `4×4` 月历同屏展示整月视图与选中日待办安排，支持个人日期圆点标记，离线内置 2025–2027 年中国大陆放假与调休安排。另提供 `2×2` 每周速览月历。时钟与天气提供 `2×2` 实况卡片与 `3×2` 逐小时横滑预报（共 16 小时）。
- **效率、汇率、组件包与通知** 内置便签、待办、世界时钟、专注计时、日期倒数、习惯打卡、今日面板与 `2×2` 汇率换算卡，支持预览并导入本地 JSON 组件包。各小组件支持的尺寸按组件类型分别定义。支持订阅已授权的 HTTPS JSON 通知源，顶部未读胶囊仅在有未读消息时显示。
- **外观、壁纸与联网边界** 支持跟随系统深浅色或手动切换夜间模式。可选本地 PNG / JPEG / 静态 WebP 壁纸保存在当前浏览器的 IndexedDB 中。天气定位、汇率换算与 HTTPS JSON 通知按需请求已授权网络数据源，不提供云端账号或云同步数据服务。

## 使用扩展（Chrome / Edge 新标签页）

已安装的浏览器扩展完全独立运行，数据保存在当前浏览器配置文件的 `chrome.storage.local` 与本机 IndexedDB 中，不依赖 Node.js 或本地网页服务。要求 Chromium 内核最低 **Chrome 120**。

### 首次安装

1. 下载 [LaunchDeck-v0.10.9.zip](https://github.com/limitpea-hash/LaunchDeck/releases/download/v0.10.9/LaunchDeck-v0.10.9.zip)（或访问 [v0.10.9 发布页](https://github.com/limitpea-hash/LaunchDeck/releases/tag/v0.10.9)）并解压到本地固定目录。
2. 在 Chrome 打开 `chrome://extensions/`（或 Edge 打开 `edge://extensions/`），开启右上角**开发者模式**。
3. 点击**加载已解压的扩展程序**，选中解压后直接包含 `manifest.json` 的目录。
4. 新建标签页即可使用。若希望启动浏览器时直接进入，可在浏览器设置中将“启动时”设为“打开新标签页”。

### 升级已有扩展

1. **先导出完整备份** 升级前在扩展「设置 → 数据同步 → 本地数据备份」导出完整 JSON 备份。
2. **覆盖原加载文件夹** 将 `LaunchDeck-v0.10.9.zip` 解压并覆盖到原先加载的同一个文件夹路径。切勿先卸载旧扩展，卸载会清空当前扩展 ID 下的存储数据。
3. **重新加载并刷新** 在扩展管理页点击 LaunchDeck 卡片上的**重新加载**，随后刷新新标签页。也可提前在「设置 → 更新与组件」中核对升级包版本与可选 SHA-256。

权限边界与迁移细节见 [扩展说明](backend/extension/README.md)。

## 运行网页服务与本地构建

运行本地网页服务或执行构建打包需要 **Node.js >= 24**，无第三方运行时依赖。网页服务适合个人本机或可信局域网共享导航、便签与待办数据。

```sh
# 启动网页服务（默认监听 0.0.0.0:3000）
npm start

# 仅限本机访问
LISTEN_HOST=127.0.0.1 npm start

# 运行测试与构建扩展产物
npm test
npm run build:extension
```

网页服务首次启动时在 `backend/data/` 自动创建 SQLite 数据库，本地图片壁纸仍保存在各自浏览器的 IndexedDB 中。公开仓库与发布压缩包不包含任何个人数据或备份文件。

## 备份、恢复与 Bitwarden 兼容

LaunchDeck 提供两类本地备份文件，适用边界不同：

- **扩展版完整备份（JSON）** 位于扩展「设置 → 数据同步 → 本地数据备份」。包含网站、桌面与分类页、单层文件夹、Dock 固定状态、小组件固定坐标与尺寸、便签、待办、组件配置、自定义组件包及时间地区设置，不包含本机 IndexedDB 图片壁纸。导入确认后会整体替换当前扩展内对应数据，并兼容旧版备份尺寸迁移。
- **导航专用备份与 Bitwarden 单条登录 JSON** 仅包含网站、页面与分类、文件夹、Dock 标记及小组件标识、固定坐标与尺寸，不包含便签、待办、组件内部配置、壁纸或位置设置。恢复导航备份前可预览校验，确认后保留本机原有的便签、待办与偏好。
- **Bitwarden 手动导入与独立恢复** 导出的 Bitwarden 文件为明文单条登录 JSON，需用户在 Bitwarden 保险库中手动导入后由保险库加密保存，项目不读取保险库密码或凭据。网页版可在独立恢复页配合自定义字段填充确认恢复，浏览器扩展则在内置恢复页通过粘贴备份文本或选择文件完成校验与恢复。详见 [Bitwarden 兼容性报告](backend/extension/BITWARDEN_COMPATIBILITY.md)。

## 常见问题

- **安装扩展后还需要运行 `npm start` 吗？** 不需要。扩展内置本地存储与消息运行时，脱离 Node.js 与网页服务独立工作。
- **更换电脑或重装浏览器如何迁移？** 在旧环境中导出扩展完整备份 JSON，在新环境加载扩展后导入该备份文件，本地壁纸需重新选择图片。
- **升级后天气或汇率未刷新怎么办？** 在「设置」对应联网授权项中按浏览器提示确认数据源域名权限（如大陆城市与 IP 近似定位域名 `uapis.cn`、国际天气 Open-Meteo 或汇率数据源 Frankfurter）。
